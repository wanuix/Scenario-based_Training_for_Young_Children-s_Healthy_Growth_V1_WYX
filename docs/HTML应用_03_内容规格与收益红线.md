# HTML应用_03 · 内容规格与收益红线

> **产出角色**：儿童发展内容专家（内容守门人，继承 V3.2 五方专家团）
> **上游依据**：V3.2 全案（唯一内容源）· `HTML应用_01`（P01-P19）· `HTML应用_02`（组件）
> **交付内容**：内容总则 → 收益文案（分层/分模块/分剧本）→ 剧本全字段样例 → 话术白名单 → 禁语黑名单 → 心理安全内容 → 红线校验清单
> **本文件性质**：为每页/每剧本提供**可直接填充进 JSON/页面的成品文案**，数据工程师据此建 `content` 与 `benefit` 字段。

## 一、内容总则（6 条）

1. **唯一数据源**：所有文案以 V3.2 为准，不得杜撰；里程碑只引 §12.2，剧本只引 §6.2/§6.3。
2. **白话化**：专业术语旁注大白话（如"反应抑制"→"能刹住车、不冲动"）。
3. **正向框架**：防御类内容一律包装为"勇敢游戏/魔法话术"，不渲染危险（§11.1）。
4. **口径统一**：话术与幼儿园班级用语对齐（§9.2），避免规则错位。
5. **禁语零容忍**：任何页面、按钮、提示都不得出现第五节黑名单词。
6. **收益可见**：每个模块/剧本必须有一句"对孩子的好处"，让家长知道"为什么练"。

## 二、收益文案 · 分层（P0-P5 + L，用于 P17 分层收益页）

| 层 | 一句话收益（对孩子的好处） |
|----|--------------------------|
| **P0 基石** | 情绪稳、有安全感，是一切训练的前提——孩子不焦虑，才学得进任何本领。 |
| **P1 核心** | 打破"被伤害→沉默"的本能，让孩子被掐被推时能喊停、会求助，不再默默承受。 |
| **P2 根因** | 打通"语言通道"+装上"情绪闸门"，从根上解决抢玩具与说不出，标本兼治。 |
| **P3 行为** | 学会用嘴巴代替手——先问再拿、换着玩，成为受欢迎的小朋友。 |
| **P4 预防** | 抬头挺胸、声音响亮、跑得动跳得高，个子小也有大气场和存在感。 |
| **P5 发展** | 交到朋友是"治本"——有了玩伴，被欺负、抢玩具、不敢说都会大幅缓解。 |
| **L 支撑** | 会洗手、会报病、会防走失、返园顺利，健康地基托住上面所有训练。 |

**收益总纲（用于 P16 收益总览页）**：
- **本质问题**：不是教孩子打回去，而是帮她在"被伤害→沉默"之外，建立一条新神经通路：**被伤害 → 喊停 → 表达 → 求助 → 走开**（§2.2）。
- **核心公式**：**孩子演练 + 成功体验 + 庆祝强化 = 新的条件反射**（§4.3）。
- **治本结论**：一个孩子如果情绪稳定、能自理、守规则、会表达、有朋友——她几乎不会被欺负（§4.2）。

## 五、剧本全字段成品样例（供数据工程师 1:1 建结构）

### 样例 1 · B01

```yaml
编号: B01
名称: 三步应对·基础篇（成功体验）
模块: B 三步应对
优先级: P1核心
阶段: 近期(9-10月)
执行方式: 正式演练
参与人: [妈妈(导演/扮老师), 爸爸(对手戏), 孩子]
角色分配:
  妈妈: 导演，示范"老师"口吻（延迟1-2分钟才回应，孩子需说两遍）
  爸爸: 演"掐人的淘气者"，用夸张搞笑表情，不用痛苦表情
  孩子: 主角，练喊"停"
台词:
  - 角色: 孩子
    内容: 停！不许掐我！（1米外能听清）
  - 角色: 爸爸
    内容: 哎呀，我松开啦，我听到你喊停了！
五步流程: [状态检查(给选择权), 看情景卡, 正式演练(先单练喊停,成功5次), 角色互换(可选), 庆祝+复盘一句话]
关键原则:
  - 先单练喊"停"，成功5次后再连"停→说→走"
  - 音量标尺：1米外能听清（用门框距离做标尺）
  - 成功结局多样化："对方不听但走开找老师"同样算成功
操作红线: 爸爸用夸张搞笑而非痛苦表情；禁说"你就是掐人的那个"；允许孩子只当观众
对孩子的好处: 练这个，孩子能把"停！"变成脱口而出的本能，被掐时不再沉默承受。
关联里程碑: "#1 三步应对：家中演练100%喊停(音量1米外可闻)"
道具: 无（或玩偶）
来源: §6.2 / §7.3 / §6.4-1
```

## 七、禁语黑名单（全站强制过滤 · §5.4）

**任何页面/按钮/提示均不得出现下列表达：**

| ❌ 禁语 | ✅ 改成这样说 |
|--------|-------------|
| 今天有人欺负你吗 / 有人抢你玩具吗 | 今天最开心的事是什么？有没有哪件事有点难？ |
| 她胆小 / 她抢不过别人 / 她不爱说话 | 她在观察，她有自己的节奏 |
| 她矮 / 她个子小 | （生长评估结论出来前，全家禁说；用"她跑得越来越快"） |
| 打回去！ | 大声说"停"，然后找老师 |
| 谁干的！我去找他 / 都怪你不说 | 你告诉妈妈，就是勇敢 |
| 没姥姥带你下楼了 | 姥姥回自己的家，我们视频里见 |
| （接园）哭了没？ | 今天玩了什么好玩的？ |

## 八、心理安全内容（用于 P18 · §14）

**预警信号清单（柔和黄底展示，非惊悚红）**：
- 演练中：抗拒躲藏拒绝参与 / 演后低落>30分钟 / 反复重演"被掐"且表情紧张 / 喊停后仍被打不反抗
- 生活里：夜惊梦呓增多 / 突然拒绝上幼儿园 / 出门前黏人升级 / 退化行为(尿裤/吃手/叠字) / 恐惧特定同伴名字 / 无因身体主诉(肚子疼)

**降级流程（可视化步骤）**：
```
当日改纯发展类游戏 → 冲突剧本停48小时 → 观众身份重入 → 1周内不升级难度
持续≥1周 → 暂停B/C/A全部模块 → 回归H情绪基石 → 寻求专业评估
```
**提示语**：任一信号出现即降级；两项或持续 3 天即暂停并咨询儿童心理专业人员。

**孩子主权条款（醒目置顶）**：T字暂停手势全员收戏 · 退出即成功(贴纸照给) · 观察位也算参与 · 连续2天拒绝搁置2周。
