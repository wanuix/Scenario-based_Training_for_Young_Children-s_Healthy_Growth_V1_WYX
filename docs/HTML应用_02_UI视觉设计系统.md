> **产出角色**：视觉设计师（UI）
> **上游依据**：`HTML应用_00_项目章程.md` · `HTML应用_01_UX信息架构与导航.md`（P01-P19）

## 一、视觉语言（Mood & Tone）

| 关键词 | 含义 | 落地 |
|--------|------|------|
| **温暖** | 家庭亲子氛围，不冰冷 | 暖橙强调色 + 柔和圆角 + 米白底 |
| **平静** | 不制造焦虑/危险感 | 蓝绿主色、低饱和、无刺眼红大块 |
| **清晰** | 老人也能看懂 | 高对比、大字号、强分区 |
| **鼓励** | 以成功体验为主 | 庆祝用暖色徽章，但**无惩罚性视觉**（无红叉/扣分/灰暗） |

> **红线**：防御类内容（B/C/A）视觉包装为"勇敢游戏/魔法话术"，用盾牌🛡️、星星⭐等正向图标，**禁用**警告三角、敌人、拳头等威胁意象（§11.1、§3.1）。

## 三、组件规范（Component Spec）

| 组件 | 用途 | 关键规格 |
|------|------|---------|
| **AppBar** 顶栏 | 页面标题+返回+大字开关 | 高 52px；左返回箭头(≥44×44 点击区)；标题 `--fs-h1` 居中/左对齐 |
| **TabBar** 底部导航 | 5 主 Tab 切换 | 高 56px+安全区；图标 24px+标签 `--fs-tag`；选中态 `--color-primary` |
| **SectionCard** 内容卡 | 承载每段内容 | `--surface`+`--r-card`+`--shadow-card`；内边距 `--sp-4` |
| **ScriptCard** 剧本卡 | 列表中的剧本条目 | 左侧 4px 模块色条；编号徽章(如 B01)；标题 `--fs-h2`；底部标签行(优先级/阶段/执行方式) |
| **Badge/Tag** 标签 | 优先级/模块/阶段/档位 | 圆角 `--r-chip`；`--fs-tag`；用对应 `--p*`/`--grade-*` 浅色底+深色字 |
| **AnchorChips** 锚点胶囊 | 详情页内快速跳转 | 横向滚动；如"台词/流程/收益/红线" |
| **LargeCard** 大字卡 | 老人台词卡(P04) | 台词 `--fs-large-card` 加粗；动作图示；高对比；可打印 |
| **Timeline** 时间轴 | 日历条(P12) | 横向滚动节点；当前节点高亮 `--color-accent` |
| **DataTable** 数据表 | 里程碑双标尺(P11) | 斑马纹；表头吸顶；窄屏可横向滚动 |
| **PhraseCard** 话术卡 | 三问/三档/接稳赋界(P18) | 引用样式；左侧色条；分点清晰 |
| **AlertCard** 提示卡 | 预警信号/禁语(P18) | 禁语=灰底删除线示意；预警=柔和黄底(**非惊悚红**) |
| **Button** 按钮 | 主要/次要/文字 | 主=`--color-primary`实心；次=描边；文字=无底；高≥44px |
| **FAB/底部操作条** | 剧本详情快捷操作 | 悬浮底部：看大字卡/看角色/看收益 |

## 四、关键页高保真描述（开发据此还原）

### P01 今天·首页
- 顶：AppBar（标题"家庭情景演练" + 右侧「大字」开关 + 搜索）。
- 当前节段徽标：胶囊，`--color-primary-soft` 底，文案"第0周·安全底座(9.3-9.6)"。
- **今日卡片**（视觉焦点）：大号 SectionCard，暖橙左边条，内含"今日重点"列表 + 主按钮「查看今日剧本 →」。
- 本周剧本：ScriptCard 纵向列表（编号徽章 + 标题 + 优先级标签）。
- 关键日历：横向 Timeline，当前节点(9.4)高亮。
- 快捷入口：3 个方形卡片（话术卡/安全/本周），图标 + 文字。
- 底：TabBar，"今天"选中。

### P03 剧本详情
- 顶：AppBar（返回 + "B01 三步应对·基础篇"）。
- 头部区：大号编号徽章 + 模块色条 + 标签行（P1核心/近期/正式演练）。
- AnchorChips：台词 · 角色 · 5步流程 · 关键原则 · 红线 · 对孩子的好处 · 里程碑。
- 内容分区卡片：
  - **台词**：对话气泡样式（大人/孩子分色），关键词加粗。
  - **5步流程**：编号步骤条（状态检查→看卡片→演练→角色互换→庆祝+复盘）。
  - **对孩子的好处**：`--color-accent-soft` 底强调卡（收益字段）。
  - **红线**：AlertCard 柔和黄底。
- 底：悬浮操作条（看大字卡/看角色/看收益）。

### P04 大字卡模式
- 全屏极简：超大台词（`--fs-large-card`）居中，动作图示，最少装饰。
- 顶部小字：剧本编号 + "第 X 句/共 Y 句"。
- 右下：「打印上墙」按钮（触发浏览器打印样式）。

### P05 角色总览
- 金字塔分层卡（总执行/主执行/日常渗透/特设21天），每层不同浅色底。
- 成员头像圆形按钮 → 进 P06。

### P16 收益总览
- 核心公式视觉化：`演练 + 成功体验 + 庆祝 = 新条件反射`（图形/图标）。
- 新神经通路流程：被伤害→喊停→表达→求助→走开（横向步骤图）。
- 治本结论卡：情绪稳+能自理+守规则+会表达+有朋友。

### P18 安全话术底座
- 顶部锚点：孩子主权 · 复盘三问 · 三档口诀 · 三层圈 · 接稳赋界 · 禁语 · 预警 · 铁律。
- 三档口诀：红/黄/绿三色卡（`--grade-*`）。
- 禁语清单：灰底 + 删除线示意 + 旁注"改成这样说"。

## 五、图标与插画风格

- **图标**：线性 + 圆润端点，2px 描边，24px 网格；emoji 作为轻量占位（🏠🎭👨‍👩‍👧🗓️💡🛡️⭐🧸）。
- **插画**（可选）：扁平、柔和、亲子场景；避免写实、避免冲突/哭喊画面。
- **模块图标建议**：A身体盾牌🛡️ · B三步应对🚦 · C求助🙋 · D社交🧸 · E物权🤝 · F共情💗 · G适应👋 · H情绪🌈 · I自理🧦 · J规则📏 · K语言💬 · L健康🧼。

## 六、适老化与无障碍（硬指标）

| 项 | 标准 |
|----|------|
| 对比度 | 正文/背景 ≥ 4.5:1；大字 ≥ 3:1 |
| 点击区 | 所有可点元素 ≥ 44×44px |
| 默认字号 | 正文 ≥ 17px；提供「大字模式」全局开关（放大至 22px+） |
| 行高/字距 | 行高 1.7；段间距充足 |
| 色彩不单独承载信息 | 优先级除颜色外**必有文字标签**（色盲友好） |
| 语言 | 全中文，短句，避免术语；专业词旁注白话 |

## 七、打印样式（大字卡上墙 · §5.8/§8.3）

```css
@media print{
  .appbar,.tabbar,.fab,.anchor-chips{display:none!important;}
  body{background:#fff;color:#000;}
  .large-card{font-size:34px;line-height:1.6;page-break-inside:avoid;}
  .print-only{display:block;}   /* 打印时显示"贴冰箱/上墙"提示 */
}
```
- 大字卡 P04 一键打印：只印台词 + 动作 + 编号，黑白高对比，A4 居中。

## 八、给开发的实现约定

1. **CSS 变量单一来源**：第二节令牌写入 `assets/css/tokens.css`，全站引用；换肤只改变量。
2. **组件类名**：BEM 风格，如 `.script-card`、`.script-card__badge`、`.script-card--p1`。
3. **优先级色映射**：`.tag--p0{background:var(--p0-soft);color:var(--p0)}`（每色配浅底）。
4. **大字模式**：切换 `html[data-large]`，不刷新页面，纯 CSS 生效。
5. **响应式**：以 360-430px 竖屏为基准；平板/桌面居中限宽 480px（模拟手机）。
6. **图标**：优先 emoji（零依赖）；需要统一风格时再引入 inline SVG（不引外部图标库，减依赖）。
7. **无框架视觉依赖**：不引入 UI 组件库，纯手写 CSS，保证 GitHub Pages 直开、离线可用。
