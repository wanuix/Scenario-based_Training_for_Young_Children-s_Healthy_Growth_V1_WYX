## 第二部分 · 产品方案汇总

### 2.1 产品定位与价值主张
- **本质**：不是训练追踪工具，而是"**看懂并照着做**"的家庭速查手册（用户明确要求）。
- **价值**：妈妈晚间 10 分钟打开手机即知"今天演什么、谁配合、怎么演、为什么练"；老人用大字卡照着念；全家口径统一。
- **北极星**：让 V3.2 的方法论**每天可触达、可执行**，且不违背任何儿童安全红线。

### 2.2 信息架构（5 板块 → 18 页）

| Tab | 板块 | 页面 | 一句话 |
|-----|------|------|--------|
| 🏠 今天 | 今日/本周速查 | P01 | 打开即见今天演什么 |
| 🎭 剧本 | 剧本库/详情/大字卡 | P02-P04 | 52 剧本怎么演 |
| 👨‍👩‍👧 角色 | 分工/成员/21天专项 | P05-P07 | 每个人做什么 |
| 🗓️ 计划 | 优先级/阶段/里程碑/日历/节段/健康/家园 | P08-P15 | 整体怎么走 |
| 💡 收益 | 收益总览/分层/安全话术底座 | P16-P18 | 为什么练+安全底线 |

（P19 关于页可选。详见 `HTML应用_01`。）

### 2.3 核心用户流程（4 条）
1. **妈妈晚间**：打开 → 首页今日剧本 → 详情（台词/流程/收益）→ 大字卡给老人。
2. **老人**：角色 Tab → 点自己头像 → 大字卡照着念（≤3 步）。
3. **家长查价值**：收益 Tab → 核心公式/分层收益（或剧本详情内嵌收益）。
4. **应急安全**：首页快捷卡 → 安全话术底座（禁语/预警/主权，2 击可达）。

### 2.4 内容与收益（内容专家成品，直接填充）
- **收益三层**：总纲（新神经通路+核心公式）→ 分层（P0-P5+L 各一句）→ 分剧本（52 条 benefit 字段）。
- **话术白名单**：复盘三问 / 三档口诀 / 三层圈 / 求助双版 / 接稳赋界 / 音量标尺 / 道别固定话。
- **禁语黑名单**：7 类强制过滤 + "改成这样说"替换（全站 0 命中）。
- 全部成品文案见 `HTML应用_03`。

### 2.5 视觉与体验
- **视觉语言**：温暖·平静·清晰·鼓励；蓝绿主色 + 暖橙强调；六层优先级色 + 红黄绿三档色。
- **适老化硬指标**：正文≥17px、大字模式≥22px、对比度≥4.5:1、点击区≥44px、层级≤3、颜色不单独承载信息。
- 设计令牌与组件规格见 `HTML应用_02`（可直接复制为 CSS 变量）。

## 第三部分 · 开发方案汇总

### 3.1 技术选型（决策已定）
**原生 HTML + CSS + Vanilla JS（ES Module）· 轻量 Hash SPA · 7 个静态 JSON · GitHub Pages · 轻量 PWA。**
- 理由：零构建、零依赖、零维护，git push 即上线，其他 AI 上手成本最低，天然离线。
- 明确不引入：前端框架/构建链（除非团队坚持，则平移 Vite+Vue 但保留"纯静态无后端"）。

### 3.2 架构与数据流
```
index.html(SPA外壳) → app.js(启动) → data.js(fetch 7 JSON 到内存)
   → router.js(hash→view) → views/*.js(渲染 P01-P19)
   → today.js(★客户端日期算法: 今天/本周/回落)
   → sw.js(PWA 离线缓存)
全程只读，无任何服务端/写入
```

### 3.3 数据契约（7 个 JSON）
`meta / modules / scripts(52) / family / plan / benefit / safety`——TS 接口定义、样例、7 条校验规则见 `HTML应用_04`。内容与代码分离：**改内容只改 JSON，代码零改动**。

### 3.4 仓库结构
```
repo-root/ (Pages源=root, 分支=main)
├── index.html  manifest.webmanifest  sw.js
├── assets/{css,js,icons}/   js/views/{today,scripts,roles,plan,benefit}.js
├── data/*.json (7)          tools/validate-data.mjs
├── docs/ (本套 00-07 设计文档)   .github/workflows/validate.yml   README.md
```
**路径铁律**：全站相对路径（项目页 URL 带 `/repo/` 前缀，绝对路径会 404）。

### 3.5 关键机制
- **日期视图算法**（唯一"智能"）：`localISO()` 取本地日期 → 匹配 `plan.phases` 的 `[from,to]` → 得当前节段与今日剧本；空档取下一节段，超范围回落长期。**只读，不写存储。**
- **大字模式**：切 `html[data-large]`，纯 CSS 生效（属显示偏好，非数据采集）。
- **打印**：`window.print()` + `@media print`，大字卡上墙。
- **PWA**：SW 缓存优先，预缓存全部 JSON/资源，离线可用、可加主屏。

### 3.6 部署
Settings → Pages → Source: `main` / `/ (root)` → 访问 `https://<user>.github.io/<repo>/`。仓库 Public（无隐私数据，公开无风险）。可选 CI：PR 触发数据校验，失败阻断。详见 `HTML应用_05` 五。

### 3.7 开发计划（5 Sprint · 4 里程碑）

| Sprint | 内容 | 里程碑 | 目标日 |
|--------|------|:------:|:------:|

| 1 骨架 | index/css/router/data/导航（T07-T10） | — | 9.9 |

## 第六部分 · 合并红线与验收（终检清单）

**七大红线（不可谈判）**
1. 孩子主权优先，无惩罚/扣分/断签机制；2. 心理安全监测内置可达；3. 禁语零命中；4. 防御类当日≤1、发展类收尾；5. 老人可照做（大字/台词≤2句/≤3步）；6. 数据单一权威（V3.2/§12.2/52剧本）；7. 只读无采集（零后端/零写入/零用户信息）。

**上线终检（全部勾选方可交付）**

- [ ] 体验：字号/对比度/点击区/层级达标、色盲友好；
- [ ] 技术：Pages 上线手机可开、相对路径无 404、PWA 可离线加主屏；
