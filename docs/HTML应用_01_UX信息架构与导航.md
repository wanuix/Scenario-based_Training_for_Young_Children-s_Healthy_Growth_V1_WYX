> **产出角色**：体验设计师（UX/交互）
> **上游依据**：`HTML应用_00_项目章程.md`（只读定位 + 5 板块）· V3.2 全案

## 一、UX 设计原则（8 条）

1. **打开即答案**：首页第一屏就回答"今天演什么"，无需点击即可见（妈妈晚间 10 分钟场景）。
2. **只读即浏览**：全站无输入、无提交、无加载态；所有内容本地静态渲染，秒开。
3. **层级 ≤ 3**：底部 Tab（1）→ 板块列表/总览（2）→ 详情（3）。老人也能两步到达。
4. **一屏一主题**：每页只讲一件事，长内容用锚点分段 + 顶部快速跳转。
5. **大字优先**：默认正文 ≥ 17px，剧本台词 ≥ 20px；提供"大字卡模式"（≥ 24px，可打印）。
6. **收益随处可见**：每个剧本/模块页都内嵌"对孩子的好处"，不需要跳到别处找。
7. **安全一键可达**：禁语清单、预警信号、孩子主权条款在首页设快捷入口（应急 2 击内到达）。
8. **去危险感**：文案与图标避免"危险/威胁/敌人"意象，防御类内容包装为"勇敢游戏/魔法话术"（§11.1）。

## 三、导航模型

### 3.1 底部主导航（常驻 Tab Bar，5 项）

| 位置 | Tab | 图标 | 标签 | 默认落地页 |
|:----:|-----|------|------|-----------|
| 1 | 今天 | 🏠 | 今天 | P01 |
| 2 | 剧本 | 🎭 | 剧本 | P02 |
| 3 | 角色 | 👨‍👩‍👧 | 角色 | P05 |
| 4 | 计划 | 🗓️ | 计划 | P08 |
| 5 | 收益 | 💡 | 收益 | P16 |

- Tab Bar 固定底部，拇指热区；当前 Tab 高亮。
- 5 项为移动端底部导航上限，不再增加。

### 3.2 二级/三级导航

- **二级页**（如 P02/P05/P08/P16）：顶部 AppBar = 返回箭头 + 标题 +（可选）筛选/大字切换。
- **三级页**（如 P03 剧本详情、P06 成员详情）：顶部返回上一级；页内锚点小胶囊（如剧本详情的"台词/流程/收益/红线"快速跳转）。
- **横向切换**：剧本详情 P03 支持"上一个/下一个剧本"滑动，减少返回列表的次数。

### 3.3 快捷入口（降低高频路径深度）

- 首页 P01 设 3 个快捷卡：**今日剧本**（直达 P03）、**话术卡/禁语**（直达 P18）、**本周日历**（直达 P12）。
- 剧本详情 P03 底部悬浮 3 按钮：**看大字卡**（P04）、**看角色分工**（P06）、**看收益**（锚点/P17）。

### 3.4 全局搜索（可选增强，非 MVP 必须）

- 顶部搜索框按剧本编号/名称/关键词过滤（纯前端字符串匹配，无后端）。

## 五、核心流程图（5 条主路径）

### Flow A · 妈妈晚间"今天演什么"（最高频）

```
[打开App] → P01今天(首屏即见今日剧本卡)
   → 点「今日剧本」→ P03剧本详情(台词/5步流程/参与人)
       → 需要给老人看 → P04大字卡(可打印)
       → 想确认谁配合 → 底部「看角色」→ P06成员详情
   → 演完想了解价值 → 详情页内「对孩子的好处」锚点
```

### Flow B · 老人"我要做什么"

```
[打开App] → 底部「角色」Tab → P05角色总览
   → 点自己头像(如爷爷) → P06成员详情(大字: 我的任务/出场频次/只背1-2句台词)
       → 点「大字卡」→ P04(超大字, 照着念)
```

### Flow C · 家长"为什么练这个 / 对孩子好处"

```
[打开App] → 底部「收益」Tab → P16收益总览(核心公式/新神经通路)
   → 「分层收益」→ P17(各优先级好处)
   或：任意剧本 P03 → 内嵌「对孩子的好处」段落
```

### Flow D · 家长"整体计划 / 这周下周"

```
[打开App] → 底部「计划」Tab → P08计划总览
   → P12日历时间轴(看9.16/9.18/9.19/在家周/10.8…)
   → P11里程碑(双标尺看目标) / P13特殊节段(看返园重启怎么做)
```

### Flow E · 孩子抗拒时"应急安全指引"（红线：2 击可达）

```
[打开App] → P01首页快捷卡「安全/话术」→ P18安全话术底座
   → 顶部锚点直达: 孩子主权(T字暂停/退出即成功) · 预警信号 · 降级流程 · 禁语清单
```

## 七、老人可用性导航专项（§8.3 落地）

| 障碍 | UX 对策 |
|------|--------|
| 字小看不清 | 全局「大字模式」开关（P04 默认超大字）；正文≥17px |
| 层级迷路 | 角色 Tab 一步到"我的任务"；每页显著返回；层级≤3 |
| 记不住台词 | P04 大字卡只呈现 1-2 句锁死台词 + 动作图示 |
| 不会操作筛选 | 老人路径不经过筛选：角色 Tab → 点自己头像即可 |
| 需要示范 | 剧本详情/大字卡预留"示范视频"外链位（后续增强） |

## 八、给开发的接口约定

1. **路由建议**：`#/today`(P01)、`#/scripts`(P02)、`#/script/:id`(P03)、`#/script/:id/large`(P04)、`#/roles`(P05)、`#/role/:member`(P06)、`#/roles/grandparents`(P07)、`#/plan`(P08) 及子页、`#/benefit`(P16)、`#/benefit/layers`(P17)、`#/benefit/safety`(P18)。
2. **页面 ID 稳定性**：P01-P19 作为跨文档引用锚点，UI/数据/架构文档均沿用此编号。
3. **数据绑定**：每页所需数据字段见 `HTML应用_04_数据模型与JSONSchema.md`；页面文案见 `HTML应用_03_内容规格与收益红线.md`。
4. **无状态**：所有页面首屏直出，禁止依赖任何本地存储读取。
